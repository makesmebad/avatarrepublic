# Обновление оформления закладок

1. Замените содержимое отдельно подключённого основного дизайна файлом `forum-base-without-bookmarks.css`. Остальные правила сохранены, удалены правила оформления закладок. Файл сохранён в UTF-8 и содержит соответствующий `@charset`.
2. Замените старый скрипт закладок файлом `bookmarks-layout-only.js`. Не подключайте его второй копией. Из скрипта удалено только встроенное оформление; логика API, сохранения, удаления, переходов и сворачивания сохранена.
3. Обновите подключения `test.css` и `mobile.css` до текущей версии из этого репозитория. Всё оформление закладок находится в общем блоке `Bookmarks: shared appearance for desktop and mobile` в этих файлах. Старые блоки закладок удалены, смешанные селекторы сохранены для остальных компонентов.
4. После замены обновите версии URL подключений для сброса кэша.

Тема и форум показаны в каждой карточке постоянно. Панель имеет ограниченную высоту, длинный список прокручивается внутри. Inline `display` и `left`, которыми управляет исходный скрипт, сохраняют возможность открытия и закрытия.

Проверка: Chromium, светлая/тёмная тема, ширины 320/390/1280 px, 4 и 30 закладок, длинное название, отображение деталей, прокрутка и переключение видимости. Скрипт прошёл `node --check`. Серверные операции не выполнялись при проверке.
