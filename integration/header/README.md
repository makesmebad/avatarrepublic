# Оптимизация шапки

## Установка исправления от 17 октября

Замените старый HTML шапки целиком содержимым `header-optimized.html`. В этой версии ссылки preload записаны обычным HTML перед скриптом: браузер может обнаружить их сканером предварительной загрузки, пока более ранние синхронные скрипты ещё ожидают загрузки. Не подключайте две копии шапки.

`preload-head.html` содержит тот же блок, если есть возможность разместить его ещё раньше в настоящем head. Для текущего исправления отдельная установка этого файла не обязательна. При переносе блока в head его можно удалить из начала HTML шапки, оставив остальной код.

Первоначальная подсказка выбирает изображение по prefers-color-scheme. Когда исполняется короткий скрипт, она уточняется по сохранённому forum-index-theme и текущему состоянию темы. Если сохранённая тема отличается от системной, предварительно может загрузиться также системный вариант изображения. Для максимально раннего выбора сохранённой темы блок стоит разместить до блокирующих скриптов в head.

## Что сохранено

Содержимое, ссылки, классы и CSS шапки; переключение темы; раскрытие/сворачивание; мобильная перестановка блоков. Основной монтаж не ждёт DOMContentLoaded, второй идемпотентный проход переносит поздно разобранное меню. ResizeObserver объединяет измерения через requestAnimationFrame. Наблюдатель темы отключается после переноса кнопки. Светлячки добавляются одним фрагментом в свободное время, reduced motion исключает декоративную работу.

## Проверки

Chromium: светлая/тёмная тема, 390/1280 px, ранний монтаж, перенос позднего меню и переключателя темы, раскрытие/сворачивание, изменение ширины, светлячки, отсутствие ошибок JS. Скрипты прошли node --check.

Отдельный локальный тест с искусственно задержанным на 1,5 с внешним скриптом: прежний динамический preload начинал запрос примерно на 1,6 с, декларативный — на 0,05–0,06 с до завершения блокирующего скрипта. Это проверка механизма, а не измерение производительности реального форума.

В пользовательском trace от 23:09 LCP был 10,075 с, фон шапки запрашивался на 8,199 с. Замер после установки этого исправления ещё не получен. Цепочка крупных CSS и задержки основного потока остаются отдельными факторами; изменение не гарантирует конкретного итогового LCP.
